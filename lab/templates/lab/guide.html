🔌 1. {% trans '"Kutish rejimi" (Standby) siri' %}

{% blocktranslate %} Ko'pchilik jihozlar (TV, kompyuter, zaryadchilar) o'chirilgan holatda ham rozetkaga suqilgan bo'lsa, energiya sarflashda davom etadi. Buni "vampir energiya" deb atashadi. Ularni to'liq uzib qo'yish orqali umumiy sarfni 5-10% gacha kamaytirish mumkin. {% endblocktranslate %}

💡 2. {% trans "Yoritish tizimlari" %}

{% blocktranslate %} An'anaviy cho'g'lanma lampalarni LED lampalarga almashtiring. LED lampalar 80% gacha kamroq energiya sarflaydi va 25 barobar uzoqroq xizmat qiladi. Bu eng tez va samarali tejamkorlik usulidir. {% endblocktranslate %}

❄️ 3. {% trans "Katta jihozlardan to'g'ri foydalanish" %}

{% blocktranslate %} Muzlatgich haroratini +4°C, muzxonasini esa -18°C da saqlang. Eshigini uzoq ochiq qoldirmang. Kir yuvish mashinasini faqat to'liq yuklama bilan va pastroq haroratda (30-40°C) ishlating, chunki energiyaning 90% suvni isitishga ketadi. {% endblocktranslate %}

🌍 4. {% trans "Uglerod izi (CO2 Footprint) nima?" %}

{% blocktranslate %} Elektr stansiyalarida energiya ishlab chiqarish uchun asosan gaz va ko'mir yoqiladi. Siz qancha ko'p tok ishlatsangiz, havoga shuncha ko'p issiqxona gazi (CO2) ko'tariladi. O'zbekiston sharoitida o'rtacha 1 kVt·soat energiya 0.5 kg CO2 hosil qiladi. {% endblocktranslate %}
